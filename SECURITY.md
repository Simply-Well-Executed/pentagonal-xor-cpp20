# Security policy

This repository contains a small standalone numerical C++20 program with no network access or bundled dependencies.

## Report a security issue

Please avoid posting exploit details in a public issue. Contact the repository maintainers through GitHub's private vulnerability reporting, if enabled under **Settings → Code security**, or use the organization's established private contact channel.

## Scope

The program accepts five numeric command-line inputs and validates that they are finite values within [0, 1]. Results are mathematical parity values, not claims about faces, identities, age, or relationships.
