## New native C++20 implementation

- include/niterex_web9x_ninebit.hpp: independently authored STD-free-style nine-operation core with bounds 0..511, no C++ standard-library headers, no network calls, no copied MIT implementation.
- tests/niterex_web9x_ninebit_test.cpp: exhaustive 512 by 512 bit-operation identity testing and input/boundary cases.
- src/niterex_web9x_xhtml_renderer.cpp: Windows native WriteFile to stdout generates a static XHTML 1.0 Strict page with nine computed quests and all nine original slot roles. In a native Windows PowerShell build, redirect the Release executable's output to niterex-web9x-native.xhtml.
- ci/Test-NiteRexWeb9XOutputV1.ps1: validates the generated XML with external DTD retrieval disabled, exact quests, nine separate slot rows, checksum, and lack of inline scripts. This is XML well-formedness checking, not independent XHTML 1.0 Strict DTD certification.

The native output does **not** execute browser JavaScript, process actual certificates, issue signatures, verify SVN revisions, render all arbitrary external HTML/CSS, or implement the complete original Web9.X site. CMake/CTest test results must be obtained from a real CI run before declaring PASS.
