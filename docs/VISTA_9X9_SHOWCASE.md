## Connection to the six gates and VISTA A/B/C

A production integrator could associate every computed five-ligand
observation with the original image/frame source ID, chosen landmark and
measurement protocol, calibration, 30-bit COR expected vector, an
independent witness, and a monotonic record. The current demonstration
does not have all those fields verified.

For each of nine completed native gate cycles, VISTA-A preserves source
and gate observations; VISTA-B checks the already defined invariants;
VISTA-C emits the read-only synthesized view. All three passes repeat
the same six gate history without manufacturing extra independent
measurements. Nine loops × nine stages = 81, not 216.

A visual plate can show the same frozen reference image beside each
stage. The C++ engine does not read PNG pixels or infer personal identity,
age, gender, body proportions, ancestry, medical characteristics, or
actual physical depth from pictures.

## Evidence required for the phrase "used in production"

A claim of genuine production deployment requires an attributable
environment/system identifier, release SHA, operation logs, test and
acceptance evidence, date/time, and independently retained approval.
Visual demonstrations alone do not establish these. Until such evidence
exists, describe the attached assets as **production-style examples**,
not verified operational deployments.

**Retention rule:** display/renderer changes never mutate the source
record; ambiguity remains visible. Chosen labels do not confer authority.
