# BRITISH = FAIR

**BRITISHISH-FAIR/1**, exploratory synthetic fairness experiment, no production-ranking authority

ARIRANG is a separate, explicitly **non-scoring neutral workspace**. It starts as an empty UTF-8 `ARIRANG.txt` evidence file, is hash-checked for non-mutation, and has no candidate ID, score, vote, tie-break privilege, or authority to overwrite baseline observations. It can be copied separately as a human notepad, but editing it during a frozen experiment invalidates that experiment's comparable evidence. Neither a blank file nor a missing note means consent or PASS.

The TRI HORN experiment has three independent equally weighted identities: RED, GREEN and BLUE. The original baseline is exactly (9,9,9). All three equality lines must be verified. No two-way shortcut is allowed.

After nine equal synthetic observations per color, a separate deterministic seeded trial adds one disclosed point to exactly one of the three scores. The expected winner is committed before the actual ranking is independently recomputed; disagreement is HOLD, not a retroactive change of expectation.

The schedule uses 85 seeded permutations of the three colors, yielding 255 trials with exactly 85 interventions allocated to each color. This is balanced coverage, not a claim of statistically uniform independent randomness. The original baseline never changes; actual historical PR/CI results are never edited. Git source SHA and block number derive each seed. The seed and the predicted and observed outcome appear in the TSV ledger. The experimental receipt has its own SHA-256. Historical receipts are not merged, rewritten or promoted.

This is an adversarial *synthetic* ranking canary, not proof that a real ranking is correct, not an authorization to distort real results, and not evidence of any nationality's behavior. **RELEASE=HOLD**
