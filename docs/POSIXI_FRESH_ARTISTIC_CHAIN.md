## Ownership and transformation rules

1. The historical `X_~D~o~o~m~M~a~i~n(=)` is an earlier symbolic ancestor, not a serialized or reversible encoding of the eye phrase and not the original DOS engine entry point.
2. The current eye artwork is derived **character-by-character from the plain-text eye phrase**, with an explicit `X_~` prefix, `~` before each subsequent character, and `(=)` suffix. It is a deliberate **new output string**, never an alias or byte-equivalent canonical ID.
3. The canonical terminal is authored independently as the exact case-sensitive literal `ItWasOnlyOnceILookedInTheirEye`. No Unicode normalization, case folding, substitution, or text segmentation is permitted in the frozen comparison.
4. An artistic **UP** hop and **DOWN** hop display the same derived image without moving, editing, renaming or merging the canonical identity. `TURN` is the TriDi middle orientation.
5. No shell variables, format substitutions, loop, recursion or shell evaluation is added to `ci/FRESH-GammaGamma.sh`. No production release/build is authorized by this record.
6. This version adds output lines and is therefore NOT stdout-equivalent to earlier FRESH versions. Do not compare experimental results as if the protocol were unchanged.
