# MINZA Pinwheel Atlas · Hanzeye 九眼 · reversible origami plates

**Status:** EXPLORATORY independent presentation adapter. **License:** 0BSD.
**Authority:** original source coordinates and recorded source data; all displayed plates and audits are derived. **No changes** to the canonical Pentagonal XOR kernel, six-stage `Machine`, COR register, or VISTA 9×9 source.

## Identity, model, and non-mutation

- Preserve the exact title case: **MINZA Pinwheel Atlas**, not `ATLAS`. **Hanzeye 九眼** denotes nine audit perspectives, not physical eyes.
- A front-only image can be projected onto a 3×3 hinged net. Nine UV tiles have fixed source neighbors and may rotate, fold, flatten and reverse their traversal; they are **not nine independent photographs**.
- Keep the reverse surface invisible and remove decorative elements that obscure the front. Camera orbit and hinge animation are **display views, not recovered facial 3D geometry**.
- The source frame, source timestamp, original dimensions, UV mapping, renderer, algorithm revision and declaration instance are separately auditable. D11/axis 12 remains a declaration/provenance coordinate; don't silently reinterpret it as depth.
- A cached timestamp may contain 15 fractional digits for femtosecond-addressing without creating additional source observations.
- An unchanged baseline is always available via **ALL PLATES OFF**. No derived result may rewrite source pixels.
- Do not publish the personal source video or frame crops in the repository. The public model is independent of those inputs.

## Controls and custody

**Every image treatment has an independent, boldly labeled `ON`/`OFF` button** with a textual state and `aria-pressed` equivalent. No checkboxes or radio inputs. A closed plate has no effect on the baseline. Controls may be enabled concurrently, but overlapping alpha-composited images are not new measurements.

Existing six base plates:
1. PENTAGONAL AND (pixel agreement).
2. TEMPORAL CHANGE (disagreement display).
3. FIGURE-8 / FACE (adjustable purely geometric curve).
4. JOINT / HEXAGON (adjustable regular hexagon).
5. TEXTURE STRIP (local high-frequency visible contrast, no restoration claim).
6. HANZEYE 九眼 (source-coordinate boundaries).

Additional 21 plates:
- Five gate inspections: XOR, OR, NOP, local COR, read-only VISTA.
- RGB: RED / 红 hóng; GREEN / 绿 lǜ; BLUE / 蓝 lán.
- CMYK: CYAN / 青 qīng; MAGENTA / 洋红 yánghóng; YELLOW / 黄 huáng; BLACK / 黑 hēi.
- Three **approximate** color-vision views: protanopia, deuteranopia, tritanopia.
- Five custom directional axes: RED↔GREEN, BLUE↔YELLOW, PURPLE↔BLUE, GREEN↔RED, LAVENDER↔LYLACK (requested spelling).
- MONOCHROMATIX hexagon/grayscale.

**Total: 27 separately removable plates**, plus non-plate action buttons: FLOP (schedule next existing tick), VISTA-A/B/C read-only snapshots, source-pixel RGBA64 inspect, SHOWCASE FAN, ALL PLATES OFF, audit export, rotation, unfold and time controls. Documents get `OPEN` buttons, **never executable** by default.

The ordinary plate Z-separation is a display property (0.06 CSS px/layer in the initial prototype), not a physical measurement. SHOWCASE FAN visibly separates them for inspection; turning it OFF returns them close to the source.

## Gate / VISTA relationship

The canonical scheduler is **XOR → OR → AND → NOP → COR → FLOP → (next tick XOR)**. Do not add a seventh XOR tick. VISTA-A / VISTA-B / VISTA-C are three read-only observation passes *after* an existing six-gate cycle in the independent nine-stage adapter. Read [PENTAGONAL_GATE_CASCADE.md](PENTAGONAL_GATE_CASCADE.md) and [VISTA_9X9.md](VISTA_9X9.md).

The Atlas `local COR` display is a five-bit mismatch view, **not** the canonical 64-bit six-block COR operand. The overlays cannot verify personal identity, authenticity, age, rank, or printer origin.

## Audit record

Record `source_token`, source frame/index, requested timestamp, actually displayed timestamp, plate ID, boolean ON/OFF, gate tolerance, five circular indices, all transformation parameters, local results, reason, and protocol revision. Avoid using the exported local log as evidence of cryptographic independent authentication.

Provenance order: `source → coordinates → sampling → derived gates/color values → plate → render → audit`. Render grouping and fan-out never mutate the source or its witness.
A browser session log is not a certified external witness or immutable store.
