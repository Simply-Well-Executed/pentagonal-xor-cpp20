## Identity, model, and non-mutation

- Preserve the exact title case: **MINZA Pinwheel Atlas**, not `ATLAS`. **Hanzeye 九眼** denotes nine audit perspectives, not physical eyes.
- A front-only image can be projected onto a 3×3 hinged net. Nine UV tiles have fixed source neighbors and may rotate, fold, flatten and reverse their traversal; they are **not nine independent photographs**.
- Keep the reverse surface invisible and remove decorative elements that obscure the front. Camera orbit and hinge animation are **display views, not recovered facial 3D geometry**.
- The source frame, source timestamp, original dimensions, UV mapping, renderer, algorithm revision and declaration instance are separately auditable. D11/axis 12 remains a declaration/provenance coordinate; don't silently reinterpret it as depth.
- A cached timestamp may contain 15 fractional digits for femtosecond-addressing without creating additional source observations.
- An unchanged baseline is always available via **ALL PLATES OFF**. No derived result may rewrite source pixels.
- Do not publish the personal source video or frame crops in the repository. The public model is independent of those inputs.

## Nine explicit terminal route buttons

Display the nine zero-based terminal-route labels in exactly this order:

```text
loop index:   0    1    2    3    4    5    6    7    8
terminal:   FLOP FLIP FLOP FLIP FLOP FLIP FLOP FLIP FLOP
```

Each bold route button **selects** a loop; it does not mutate its image,
execute another native instruction, or imply a new camera view. A separate
`RUN TERMINAL` button **records** the loop, native final FLOP,
experimental terminal label, before/after direction, and next-loop index
before advancing. Odd-index FLIP toggles the presentation route's direction.
Even-index FLOP leaves that direction unchanged. Four FLIPs return the
ninth loop to the starting FORWARD orientation.

All native six-gate loops still end in FLOP. Do not count the route
FLIP as a substituted gate or a tenth VISTA step. Keep the HTML and
XHTML byte-equivalent and every image-treatment plate independently
removable through bold ON/OFF controls.

The 0BSD license covers owned viewer code and original project writing;
it does not automatically license user-provided or third-party video frames.

## Gate / VISTA relationship

The canonical scheduler is **XOR → OR → AND → NOP → COR → FLOP → (next tick XOR)**. Do not add a seventh XOR tick. VISTA-A / VISTA-B / VISTA-C are three read-only observation passes *after* an existing six-gate cycle in the independent nine-stage adapter. Read [PENTAGONAL_GATE_CASCADE.md](PENTAGONAL_GATE_CASCADE.md) and [VISTA_9X9.md](VISTA_9X9.md).

The Atlas `local COR` display is a five-bit mismatch view, **not** the canonical 64-bit six-block COR operand. The overlays cannot verify personal identity, authenticity, age, rank, or printer origin.

## NINZA / PING opt-in plates (v8)

Expose separate bold ON/OFF controls for **NINZA UNFORGE** and **PING UNTWIRL**. UNFORGE separates the nine primary and mirrored six-byte NINZA lanes and displays bytewise XOR differences. UNTWIRL uses the exact six-column, nine-position inverse PING permutation and prints source and destination indices; it never guesses missing data. Both overlays remain attached to the same nine source-UV tiles, and ALL PLATES OFF removes them. The two mirror streams are copied from one source, not independent witnesses. See [NINZA_PING_UNFORGE_UNTWIRL.md](NINZA_PING_UNFORGE_UNTWIRL.md) and its C++20 reference header. The original source bytes are unchanged.
