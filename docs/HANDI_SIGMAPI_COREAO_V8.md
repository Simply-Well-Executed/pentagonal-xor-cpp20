If a preceding ROT42 made the center `U`, the additional center correction is ROT20 (`U→O`). The derived display keeps exactly 3 characters; any suffix is **not copied** and its omitted length is recorded. This is a scoped output projection, not physical deletion, an actual `/dev/null` system call, or source mutation.
