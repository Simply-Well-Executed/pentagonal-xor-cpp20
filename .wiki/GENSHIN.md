# GENSHIN — Geometry and BiDi Witnesses

| Interface | Purpose |
|---|---|
| `genshin_bias::detect` | Reverse registered contour folds and compute synthetic focus/score evidence |
| `genshin_bidi::project` | Apply UAX #9 L2 reordering to upstream resolved line levels |
| `genshin_tripi::inspect` | Compare a visual occurrence ledger against an independent reference |
| `genshin_zipit::ZIPITUP` and related methods | Structural role permutations; do not change audit verdicts |

BiDi projection is not a complete Unicode algorithm, renderer, font engine or grapheme shaper. Occurrence coordinates and canonical code points remain distinct from screen layout. Explicit bounds and malformed-input checks remain part of the contract.

The four standalone permutations keep their distinct implementation and fixture identities. The namespace migration uses type scopes in the headers and local functions in standalone translation units.
