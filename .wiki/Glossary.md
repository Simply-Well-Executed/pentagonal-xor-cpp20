# Glossary

| Term | Meaning in this project |
|---|---|
| AIRGAP | Logical verification boundary in ARIARI; context-specific, not a physical isolation claim |
| ALONZ | In the new bounded encoding, the caller-defined distinct alphabet; other ALONZ features have separate contracts |
| ARIRANG / ARIRONG | Forward and reverse arithmetic or encoding routes in the draft composition |
| ARIARI | Reconciliation and closure |
| COREAO | Read-only trace inspection |
| DECADAKATANA | Tenfold threshold, exposed via legacy DAKATANA gate |
| GammaGamma | Explicit decimal-component factorial difference |
| INFINITI | Checked finite cardinality calculation in the draft encoding |
| KNIGHTREX | Original work divided by remaining work |
| LCD | Project-specific reduced quotient, not conventional least common denominator |
| METALOGRI | Reversible shared-prefix encoding |
| REDUX | Reduction relative to original work |
| SILVERHAND | Serial union of test targets |
| TALON | Figure-eight-to-circle deformation and separate sphere drop model |
| THAILONGA | Fusion/factorization operation, with context-specific contracts |
| TOOLONG | Existing arbitrary-precision integer arithmetic |
| TRIFORCE | Three-way integrity and paired HEAD/TAIL evidence contract, depending on context |
| UNION | Task composition preserving individual evidence; not C++ union storage |

Names are project vocabulary. Mathematical facts must be established independently of naming.
