# THAILONGA Wizmacker SPOOL

Copr.© 2026 by PAUL ALLEN CHEEK mail@pcheek.com C5824

CURRENT design: integrate arbitrary Unicode multi-spool editing into THAILONGA Wizmacker. No fixed alphabet, length, prefix, or spool count; finite hardware limits apply. Preserve each spool's identity, exact code points, undo history and exportable audit. Explicit append, reverse, rotate, compare, duplicate, rename, remove; no silent normalization or merging. Accessibility requires labeled keyboard, touch and switch-friendly controls with reserved AIRGAP. String play does not execute arbitrary opcode text. Canonical operator junction notation remains `[XOR][AIRGAP][OR]` unless explicitly configured. Preserve DIHAODA operator exclusions and namespace distinctions. RELEASE=HOLD until C++20 implementation and native tests pass.
