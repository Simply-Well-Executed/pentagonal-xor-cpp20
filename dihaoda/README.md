# DIHAODA Wizmacker

Copr.© 2026 by PAUL ALLEN CHEEK mail@pcheek.com C5824

DIHAODA is an independently explorable topology lab, distinct from DIAERY. All gates must be visible and keyboard, touch and assistive pointer accessible. `[XOR][AIRGAP][OR]` is the default, not a limit. Custom COR and COREAO behaviors require explicit definitions; no implicit route choice. Keep free access and preserve data and provenance. Release HOLD until native tests pass.
