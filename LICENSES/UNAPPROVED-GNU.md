# Other unapproved GNU families: deny unless explicitly authorized

This is a **policy index**, not a fabricated universal "GNU license" text. The locally vendored GPL v1/v2/v3, AGPL v1/v3, LGPL v2.0/v3.0, and GFDL v1.3 reference texts are examples, not an exhaustive GNU license registry. Any further GNU-family license, custom exception, or ambiguous revision must be identified by **exact title, version, SPDX ID if available, publisher, text snapshot and component grant**. It remains FORBIDDEN or REVIEW/HOLD until an explicit current operator decision. **CURRENT: no GNU license is permitted, including LGPL-2.1-only and LGPL-2.1-or-later.** Both now have FORBIDDEN lock rows. Prior LGPL-2.1 permission remains in Git history as a superseded decision, not a CURRENT exception.

Preserving a forbidden text here **never means using or adopting** that license for this repository. Historical evidence remains available even when authorization is refused.
