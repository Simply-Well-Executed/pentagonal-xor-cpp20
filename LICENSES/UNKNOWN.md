# UNKNOWN licensing: evidence required

This file is a **review record, not license terms**. There is no universal text of an "unknown license" to copy. Unknown attribution means **HOLD**, never default consent, implicit 0BSD, or automatic adoption of an approved family.

When an unknown component is identified, preserve its name, version, source URL, upstream commit or immutable release digest, installed-file paths, original copyright/NOTICE evidence, available SPDX fields, exact scan date/version, and the reviewer decision. Do not guess at rights, rewrite the notice or suppress the finding.

Record component-specific evidence in [COMPONENT_USAGE.tsv](COMPONENT_USAGE.tsv) and preserve separate source snapshots when reviewed.
